# Rozgar Voice

> A multilingual, voice-enabled vocational jobs and skills platform for blue-collar workers.

## 🚀 Live Demo
- **Vercel Deployment:** [https://rozgaar-iota.vercel.app](https://rozgaar-iota.vercel.app)

## 🌟 Features
- **Voice-first assistance**: Speech synthesis and audio guidance.
- **Multilingual Support**: English, Hindi (हिंदी), and Marathi (मराठी).
- **Skill Training & Certification**: Interactive micro-courses with badges (Site Safety, Masonry, Wiring, Lifting, Painting).
- **Verified Job Listings**: Nearby jobs with daily wages and required skill checklists.
- **Zero-Commission Direct Payments**: Instant direct UPI payments without middleman cuts.
- **Employer Portal**: Post new job openings with immediate listing updates.

## 💻 Tech Stack
- HTML5, CSS3 (Modern Glassmorphic & Accessible UI)
- Vanilla JavaScript & Web Speech API
- Hosted on Vercel
